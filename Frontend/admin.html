💾 डेटाबेस बैकअप एवं रीस्टोर सिस्टम (Backup & Restore System)

संपूर्ण डेटाबेस (प्रॉपर्टीज, ग्राम, ऑर्डर्स, अनुरोध एवं सेटिंग्स) का सुरक्षित JSON बैकअप लें अथवा रीस्टोर करें।

📥 डेटाबेस बैकअप डाउनलोड (JSON)

सर्वर पर मौजूद सभी प्रॉपर्टी रिकॉर्ड्स, ग्राम सूची, सभी ऑर्डर्स और सेटिंग्स की संपूर्ण JSON बैकअप फ़ाइल डाउनलोड करें।

🔄 बैकअप से डेटाबेस रीस्टोर करें (Restore)

पूर्व में डाउनलोड की गई JSON बैकअप फ़ाइल चुनें। रीस्टोर करने से पहले सिस्टम स्वचालित रोलबैक स्नैपशॉट भी सुरक्षित रखेगा।
